# Combined Vietnamese Medical QA Dataset

This dataset is a collection of Vietnamese medical question-answer pairs combined from multiple public sources on Hugging Face.

## Dataset Structure

The dataset contains the following columns:

- `question`: Medical question in Vietnamese.
- `answer`: Corresponding medical answer in Vietnamese.

## Sources

This dataset was created by combining data from the following datasets:

- lqkhoi/viet_med_qa
- hungnm/vietnamese-medical-qa
- tarudesu/ViHealthQA
- Dqdung205/medical-vietnamese-qa
- phucthaiv02/heath_disease_faq
